# gut Key Map

Keyboard actions accept canonical key names such as:

- `Return`
- `Escape`
- `Tab`
- `Space`
- `LeftCmd`
- `RightCmd`
- `LeftControl`
- `RightControl`
- `LeftAlt`
- `RightAlt`
- `LeftShift`
- `RightShift`
- `Up`
- `Down`
- `Left`
- `Right`

Input matching is forgiving. `left-cmd`, `Left Cmd`, and `left_cmd` all resolve to `LeftCmd`.

Use the `gut://reference/keys` MCP resource for the full generated key list.
